# NEON://SNAKE

Киберпанк-змейка для браузера: неоновая арена, уровни, боссы и полностью синтезированный звук. Без сборки, без CDN, без сети — всё в одном проекте, работает офлайн.

## Запуск

Откройте `index.html` двойным кликом в любом современном браузере (Chrome, Edge, Firefox). Игра работает прямо с диска по протоколу `file://` — интернет, сервер и установка не нужны.

## Управление

| Действие | Клавиши | Тач |
|---|---|---|
| Направление | Стрелки **и** WASD (одновременно) | Свайпы в 4 стороны (порог 24px) |
| Пауза | Space или Esc | Кнопка «Пауза» в HUD |
| Старт / рестарт | Enter (или клик/тап по полю) | Кнопки «Играть» / «Заново» |
| Звук вкл/выкл | M | Кнопка звука в HUD |

Есть буфер ввода до 3 направлений: быстрые повороты «уголком» не теряются, разворот на 180° игнорируется.

## Механика

- Арена 30×20 клеток; скорость растёт с уровнем от 7.5 до 14 тиков/с.
- Столкновение со стеной, своим телом, телом босса, лазером или файрволом — смерть. Жизнь одна.
- **Обычная еда** («пакет данных», пульсирует): +10 × уровень очков, +1 сегмент.
- **Бонус** («фрагмент кода», жёлтый): после каждых 5 съеденных обычных единиц еды появляется на 7 секунд (последние 2 секунды мигает): +250 очков, +2 сегмента.
- **Уровни**: каждые 5 съеденных обычных единиц еды — тост «УРОВЕНЬ N», рост скорости и смена цвета свечения арены (цикл: cyan → magenta → yellow → green → orange).
- Очки начисляются за еду, бонусы, заряды (+25) и убийство босса (+250 × номер босса). Рекорд сохраняется в `localStorage`.

## Боссы

Каждый 3-й уровень (3, 6, 9, …) на арену спускается босс: **СТРАЖ СЕТИ**, **ВИРУС-КОРОЛЕВА**, **АЛГОРИТМ ОМЕГА** — дальше боссы циклически усиливаются, игра бесконечна. У босса HP = 3 + номер. На поле держится зелёный **«заряд данных»**: съешьте его — босс получает урон (+25 очков), новый заряд появится через 2.2 с. Скорость змейки на время боя замораживается.

Атаки босса всегда телеграфируются (мигающее красное предупреждение):

- **Лазер** — прицельно по ряду или колонке головы: 0.9 с заряд, затем 0.5 с смертельный луч.
- **Файрвол** — 3 + номер босса оранжевых блоков в случайных свободных клетках: 0.6 с «включаются» (мигают, не смертельны), затем смертельны до конца боя (суммарно не более 18 блоков).
- **Рывок** (со 2-го босса) — 0.9 с телеграф ряда, затем босс пролетает всю арену по горизонтали на скорости 12 клеток/с.

За убийство босса — взрыв, фанфара и +250 × номер босса очков; все опасности очищаются, игра продолжается на том же уровне.

## Стек

- **HTML5 Canvas 2D** — рендер с интерполяцией движения между тиками и учётом devicePixelRatio.
- **Web Audio API** — музыка и все 12 звуковых эффектов синтезируются кодом (16-шаговый секвенсор: меню 84 BPM, игра 100 BPM, босс 128 BPM, ля-минор), без единого аудиофайла.
- **Vanilla JS** — классические скрипты без сборки и зависимостей (IIFE, единый неймспейс `window.CS`), CSS-анимации для CRT-эффектов (сканлайны, виньетка, шум, глитч-заголовок).

## Структура файлов

```
index.html      — разметка: канвас, HUD, экраны, порядок скриптов
css/style.css   — неоновый стиль, CRT-оверлеи, глитч-анимации
js/audio.js     — CS.Audio: синтезированная музыка и SFX, mute
js/bosses.js    — CS.BossFight: боссы, лазер/файрвол/рывок, заряды
js/fx.js        — CS.FX: частицы, тряска, глитч, вспышки
js/ui.js        — CS.UI: экраны, HUD, тосты, баннеры, кнопки
js/game.js      — CS.Game: ядро — змейка, еда, уровни, ввод, loop
```
