# NEON://SNAKE — Спецификация

Киберпанк-змейка для браузера. Один запуск `index.html` — без сборки, без CDN, без сети (работает с `file://`).

## 1. Обзор

- Жанр: классическая змейка на сетке с уровнями, боссами и синтезированным звуком.
- Платформа: любой современный браузер (Chrome/Edge/Firefox). Десктоп — основной, тач — поддерживается свайпами.
- Язык интерфейса: русский. Комментарии/идентификаторы кода: английские.
- Технологии: HTML5 Canvas 2D, Web Audio API, vanilla JS. **Без** ES-модулей (только классические `<script>`), **без** внешних шрифтов/библиотек — офлайн-first.

## 2. Управление (удобство — приоритет)

| Действие | Клавиши | Тач |
|---|---|---|
| Направление | Стрелки **и** WASD (одновременно) | Свайпы в 4 стороны (порог 24px) |
| Пауза | Space или Esc | Кнопка паузы в HUD |
| Старт / рестарт | Enter | Кнопки «Играть» / «Заново» |
| Звук вкл/выкл | M | Кнопка звука в HUD |

Требования:
- **Буфер ввода**: очередь до 3 направлений; каждое нажатие сравнивается с последним в очереди, разворот на 180° игнорируется. Каждый тик из очереди берётся одно направление — быстрые повороты «уголком» не теряются.
- `preventDefault()` на стрелках/пробеле, чтобы страница не скроллилась.
- Клик/тап по канвасу на экранах меню/гейм-овер = старт/рестарт.

## 3. Игровое ядро

- Сетка: **30×20 клеток**, клетка **30px**, канвас **900×600** (CSS масштабирует адаптивно, аспект сохраняется).
- Стены по краям арены — столкновение со стеной = смерть (без прохода сквозь края).
- Скорость: `ticks/сек = 7.5 + 0.5 × (level − 1)`, максимум 14. На боссе скорость замораживается.
- Змейка стартует: 4 сегмента, центр поля, движение вправо.
- Еда:
  - Обычная («пакет данных», пульсирует): **+10 × уровень** очков, +1 сегмент.
  - Бонус («фрагмент кода», жёлтая): после каждых 5 съеденных обычных появляется на 7 сек (последние 2 сек мигает), **+250** очков, +2 сегмента.
- Уровни: каждые 5 съеденных обычных единиц еды → уровень+1: тост «УРОВЕНЬ N», звук `levelup`, рост скорости, смена цвета свечения сетки (палитра-цикл).
- Очки: еда/бонус/заряды (+25)/убийство босса (+250 × номер босса). Рекорд в `localStorage` ключ `cs_best`.
- Смерть: столкновение со стеной, своим телом, телом босса, активным лазером, файрволом. Секвенция: freeze → звук `die` → частицы/тряска/глитч → 1 сек → экран Game Over со счётом и рекордом.
- Жизнь одна. Состояния: `MENU`, `PLAYING`, `BOSS`, `PAUSED`, `GAMEOVER`.

### Отрисовка движения (плавность)
Логика дискретная (тик = сдвиг на клетку). Рендер с интерполяцией: у каждого сегмента `prev{x,y}` и `curr{x,y}`; при отрисовке `t = elapsed / stepInterval` (0..1), позиция = `prev + (curr − prev) × t`. При росте новый хвостовой сегмент получает `prev = curr`. Голова рисуется с ярким свечением и «глазами» по направлению. Тело — скруглённые прямоугольники с градиентом от циановой головы к пурпурному хвосту (lerp по HSL).

## 4. Боссы

Триггер: каждый 3-й уровень (3, 6, 9, …), `bossIndex = level / 3`. Обычная еда во время боя остаётся.

Протокол боя:
- Интро 2 сек: баннер «⚠ БОСС: ИМЯ» (элемент `#boss-banner`), музыка → `boss`.
- У босса **HP = 3 + bossIndex** (4/5/6…). На поле поддерживается **1 «заряд данных»** (зелёный, +25 очков). Съел заряд → боссу 1 урон, заряд респавнится через 2.2 сек.
- Тело босса 2×2 клетки, контакты с ним смертельны. Босс двигается по клеткам, не заходя на змейку/еду/заряды.
- Цикл атак: пауза 2.5 − 0.15 × bossIndex (мин 1.6) сек → случайная атака → пауза → …
- Атаки (с телеграфом — предупреждением):
  - **Лазер**: прицельно по ряду (`head.y`) или колонке (`head.x`) головы. 0.9 сек заряд (клетки ряда мигают красным) → 0.5 сек луч: все клетки ряда/колонки смертельны. Звуки `laser_charge` / `laser_fire`.
  - **Файрвол**: 3 + bossIndex оранжевых блоков в случайных свободных клетках (не ближе 2 клеток к голове, не на еде/зарядах). 0.6 сек «включаются» (не смертельны, мигают) → далее смертельны до конца боя. Суммарный кап 18 блоков.
  - **Рывок** (bossIndex ≥ 2): телеграф ряда босса 0.9 сек → босс пролетает ряд по горизонтали (12 клеток/сек), тело смертельно, у стены останавливается.
- Поражение: взрыв, `boss_die`, +250 × bossIndex очков, все опасности очищаются, баннер «БОСС УНИЧТОЖЕН», музыка → `game`, игра продолжается на том же уровне.
- Имена: `['СТРАЖ СЕТИ', 'ВИРУС-КОРОЛЕВА', 'АЛГОРИТМ ОМЕГА']`, далее `АЛГОРИТМ ОМЕГА mk.N`. Игра бесконечна, боссы циклически усиливаются.

## 5. Звук (Web Audio API, всё синтезируется — без файлов)

Архитектура: `masterGain → compressor → destination`. `AudioContext` создаётся/резюмится по первому пользовательскому жесту (`ensure()`).

Музыка — 16-шаговый секвенсор с lookahead-планировщиком (интервал 25 мс, горизонт 0.12 с):
- `menu` (BPM 84): тёмный пэд (2 расстроенных saw через lowpass) + редкий арп (square + feedback delay 0.23 c).
- `game` (BPM 100): + кик (sine 150→40 Гц) на каждую долю, басовая линия (saw, ля-минор: A1 A1 C2 G1), хэты (шум через highpass) на восьмых.
- `boss` (BPM 128): все слои + дисторшн-бас (waveshaper) + том-филлы, арп быстрее.
- Тональность ля-минор / пентатоника, никакой диссонансной каши — «отличный звук» = чистый микс, каждая партия в своей полосе, короткий референс-громкость: музыка −6 дБ относительно SFX.

SFX (по имени): `eat` (короткий блип вверх), `bonus` (аккорд-чайм), `die` (даун-свип + шумовой краш), `levelup` (арпеджио 4 ноты вверх), `warn` (тревога 2 тона), `laser_charge` (нарастающий писк), `laser_fire` (жёсткий луч: saw+noise), `hit` (удар), `boss_die` (фанфара-взрыв), `click` (UI), `pause` (2 ноты), `start` (свип вверх).

Mute: `M` / кнопка `#mute-btn`, состояние в `localStorage` ключ `cs_muted`.

## 6. Визуальный стиль

- Фон `#04050c`, почти чёрный; панели `rgba(10,14,30,.85)`.
- Неон-палитра: cyan `#00f0ff`, magenta `#ff2bd6`, yellow `#ffe600`, danger `#ff2d55`, orange `#ff7a00`, green `#00ff9d`, линии сетки `rgba(0,240,255,.07)`.
- Акцент сетки по уровням (цикл): `#00f0ff → #ff2bd6 → #ffe600 → #00ff9d → #ff7a00`.
- Шрифт: `'Cascadia Mono', 'Consolas', 'Courier New', monospace`; заголовки — жирные, uppercase, letter-spacing, неоновое свечение (text-shadow).
- CSS-оверлеи поверх канваса: сканлайны (repeating-linear-gradient), виньетка CRT, лёгкий шум.
- Заголовок меню с глитч-анимацией (CSS keyframes: смещение/двоение в magenta/cyan).
- Кнопки: неоновые рамки, hover — заливка + свечение, активный `click`.

## 7. Архитектура и контракты (обязательны к букве)

Порядок скриптов в `index.html`: `js/audio.js`, `js/bosses.js`, `js/fx.js`, `js/ui.js`, `js/game.js`. Все модули — IIFE в strict mode, экспорт в `window.CS` (единый неймспейс). Отступы 2 пробела. Все координаты клеток `{x, y}`, x∈[0..29], y∈[0..19]; ключ клетки — строка `"x,y"`.

### `CS.Audio` (js/audio.js)
```
CS.Audio.ensure()            // создать/резюмнуть AudioContext (по жесту)
CS.Audio.music(mode)         // 'menu' | 'game' | 'boss' | null (стоп)
CS.Audio.sfx(name)           // строка из списка SFX
CS.Audio.setMuted(bool) / getMuted()
```
Вызовы до `ensure()` просто игнорируются (никаких исключений).

### `CS.BossFight` (js/bosses.js)
```
const fight = new CS.BossFight(bossIndex, gridW, gridH, events)
  events = { onDefeated(), onWarn(text), onSfx(name) }
fight.update(dt, snakeCells)   // dt сек; snakeCells = [{x,y},...] голова первая
fight.draw(g, cell)            // g=CanvasRenderingContext2D, cell=размер клетки в px
fight.hazardCells()            // Set<"x,y"> — смертельные клетки этого кадра
fight.collectCharge(x, y)      // true, если там был заряд (урон нанесён)
fight.chargeCells()            // [{x,y}] — позиции зарядов (обычно 1)
fight.active                   // bool
fight.hp / fight.maxHp / fight.name / fight.phase   // phase: 'intro'|'idle'|'telegraph'|'attack'|'dead'
```

### `CS.FX` (js/fx.js)
```
CS.FX.update(dt) / draw(g)              // draw — поверх сцены (частицы, вспышки)
CS.FX.burst(px, py, color, n)           // взрыв частиц в пиксельных координатах
CS.FX.shake(power)                      // тряска экрана
CS.FX.glitch(sec) / CS.FX.flash(color, sec)
```

### `CS.UI` (js/ui.js)
```
CS.UI.show(name)          // 'menu'|'game'|'pause'|'gameover' — переключение экранов (оверлеи)
CS.UI.hud({score, best, level})         // обновить HUD (частичный объект ок)
CS.UI.bossBar(hp, maxHp, show, name)    // show=false скрыть
CS.UI.toast(text)                        // крупная надпись по центру, сама гаснет
CS.UI.banner(text, show)                // #boss-banner
CS.UI.on({start, resume, restart, menu, mute})  // подписка на кнопки
```

### `CS.Game` (js/game.js) — оркестратор
Запускается как `CS.Game.boot()` из DOMContentLoaded. Владеет состоянием, змейкой, едой, уровнями, вводом, главным loop (`requestAnimationFrame`), интеграцией `Audio/Bosses/FX/UI`, рекордом.

## 8. DOM (id обязательны)

```
#game-canvas            канвас 900×600
#hud                    .hud: #score, #best, #level, #btn-pause, #mute-btn
#bossbar (скрыт)        #bossname, #bossfill (div, ширина %)
#toast                  центральная надпись
#boss-banner (скрыт)    баннер предупреждения о боссе
#screen-menu            заголовок, #btn-start, #btn-controls, рекорд
#screen-controls        таблица управления, #btn-controls-back

#screen-gameover        #final-score, #final-best, #btn-restart, #btn-menu2
```
Экраны — `<div class="screen">` поверх канваса (position:absolute), класс `.hidden` прячет. `CS.UI.show('game')` прячет все, показывает игру (т.е. только канвас+HUD).

## 9. Out of scope (не делаем)

- Онлайн-лидерборды, аккаунты, сохранения кроме рекорда и mute.
- Мультиплеер, достижения, настройки графики.
- Нативные аудиофайлы/внешние CDN-ассеты.
- Отдельная мобильная вёрстка (свайпы есть, но десктоп-первичен).

## 10. Плейсхолдеры

Нет — блокирующих неизвестных (оплата/ключи/хостинг) в проекте нет.
